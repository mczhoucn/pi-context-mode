# context-mode is active
Use `ctx_*` tools. The extension injects routing rules — follow them.
Note for Pi users: context-mode permissions use `.pi/context-mode/settings.json` in the project and `~/.pi/agent/context-mode/settings.json` globally. They do not fall back to `.claude/*` or `~/.pi/settings.json`. If this project also has CLAUDE.md, Pi.dev reads both files and duplicates routing instructions in context — remove one.
